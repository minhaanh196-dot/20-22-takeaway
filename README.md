# 20/22 Takeaway – Báo cáo đồ án

Slide thuyết trình HTML/CSS/JS thuần, không cần build, chạy được trên GitHub Pages.

## Cấu trúc
```
index.html
css/style.css
js/main.js
assets/images/   ← bỏ ảnh vào đây
```

## Thêm ảnh
Chép ảnh vào `assets/images/` đúng tên dưới đây (hoặc đổi `src` trong `index.html`). Chưa có ảnh thì khung hiển thị đường dẫn cần thêm.

| Slide | File |
|---|---|
| 3 | `co-so-5-lhu.jpg` |
| 6 | `key-visual.png` |
| 7 | `tra-sua-thai-do.jpg`, `tra-buoi-hoa-dao.jpg`, `houjicha-sua-hat.jpg`, `matcha-latte.jpg` |
| 8 | `post-don-mon.jpg`, `post-best-seller.jpg`, `story-ads.jpg`, `brochure-a5.jpg` |
| 9 | `posm-xe-du.jpg` |

Nên dùng ảnh ≤ 300 KB (nén bằng squoosh.app) để trang tải nhanh.

## Phím tắt
← / → / Space: chuyển slide · Home / End · F: toàn màn hình · vuốt trên điện thoại · `#5` trên URL mở thẳng slide 5.

## Đưa lên GitHub Pages
1. Tạo repo, đẩy toàn bộ thư mục lên nhánh `main`.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)` → Save.
3. Mở `https://<tên-github>.github.io/<tên-repo>/`.
